# DexSuite documentation

Source of the DexSuite docs, built with Sphinx and the PyData theme and published on Read the Docs. Pages are
Markdown (MyST) under `docs/source`.

```bash
pip install -r docs/requirements.txt
sphinx-build -b html docs/source docs/_build/html
python -m http.server --bind 127.0.0.1 -d docs/_build/html 8000      # http://localhost:8000
```

For live reload while writing: `pip install sphinx-autobuild` and
`sphinx-autobuild --host 127.0.0.1 docs/source docs/_build/html`.

The task and robot pages, the reference pages, the renders and the diagrams are generated by the scripts in `tools/`
(see `docs/source/reference/contributing.md`). They read the DexSuite source and the Genesis exports of its scenes,
so run them on a machine with DexSuite installed, then commit the results; Read the Docs only runs Sphinx.
